# Consulta diagnóstica

Herramienta de trabajo para clínicos: se eligen una o varias hipótesis diagnósticas y, para cada una, la página muestra los criterios del DSM-5-TR para verificar en la entrevista (resumidos, no textuales), con qué diferenciarla, sus códigos (DSM-5-TR, CIE-10 y CIE-11) y los planes, instrumentos y fichas de las guías de intervención.

No diagnostica: el criterio clínico es de quien la usa. Lo que se marca queda en el navegador; no se guarda ni se envía.

Los códigos CIE-10 y CIE-11 deben verificarse en la clasificación oficial antes de registrarlos.

Página: https://juanboya7.github.io/consulta-diagnostica/
